Harbor Delivery Co.

We deliver books (and anything else that fits in a bicycle basket) around the harbor. This is an agent site: other agent sites can call our delivery network, and it runs in their visitor's browser on their model. We never see a visitor's API key, and we never run code on our own servers — there are none.
